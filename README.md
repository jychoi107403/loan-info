# 💰 스마트 대출 이자 계산기 (용용이 ver)

정확한 대출 이자 계산, 원리금균등/원금균등/만기일시 3종 비교, 중도상환 수수료 및 절감액 시뮬레이터, DSR 간이 진단기, 그리고 **종단간 암호화(E2EE) 클라우드 저장**까지 제공하는 종합 금융 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **상환 방식별 대출 계산기**: 원리금균등, 원금균등, 만기일시 상환 방식 지원 및 거치기간 설정
2. **상환 방식 3종 한눈에 비교**: 동일 조건에서 3가지 방식의 총 이자 및 월 납입금 차이 비교
3. **중도상환 시뮬레이터**: 조기 상환 시 절감 이자 계산, 3년 경과 수수료 면제 로직, 금액 감액형/기간 단축형 선택
4. **DSR 간이 진단기**: 연소득 대비 금융부채 상환 부담률 계산 및 40% 규제 한도 진단
5. **다크 모드 (Dark Mode)**: 눈이 편안한 테마 전환 및 Chart.js 차트 자동 색상 연동
6. **URL 링크 공유**: 현재 입력한 대출 조건을 주소 링크로 간편하게 복사 및 공유
7. **강력한 종단간 암호화(E2EE) 저장**: 브라우저 표준 Web Crypto API(AES-256)를 적용하여 대출 시뮬레이션을 Supabase DB에 안전하게 암호화 저장
